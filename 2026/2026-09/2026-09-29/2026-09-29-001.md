---

### What the Script Does Automatically

1. **Starts the VM (if stopped)**: Sends the `start-instances` command to AWS
   and polls until the state transitions to `running`.
2. **Retrieves Fresh Dynamic Public IP**: Fetches the newly assigned public IPv4
   address without needing to open the AWS Console.
3. **Waits for Windows & RDP Service Readiness**: Actively polls TCP port `3389`
   until Windows finishes booting and is ready to accept connections (preventing
   the connection failure error caused by launching RDP too early).
4. **Notifies You**:
    - Triggers a native **Windows 10/11 Desktop Toast notification** banner
      (_"AWS Windows PC Ready"_).
    - Plays an **audio alert chime**.
5. **Launches Remote Desktop (`mstsc.exe`)**: Automatically generates an RDP
   session with:
    - Target Public IP pre-filled.
    - Username set to `Administrator`.
    - **Clipboard sharing** enabled.
    - **Local Drive Redirection** enabled (your local `C:` drive is accessible
      inside the VM for file transfer).

### How to Run

#### Option 1: One-Click Desktop Shortcut (Easiest)

Double-click
[aws/connect_ec2.bat](file:///C:/usr/src/df/manuals/aws/connect_ec2.bat) from
File Explorer (or create a desktop shortcut to it).

#### Option 2: Using Python

```powershell
python aws/start_and_connect.py
```

_(Uses only standard library modules; no `pip install` required)._

#### Option 3: Using PowerShell

```powershell
.\aws\start_and_connect.ps1
```

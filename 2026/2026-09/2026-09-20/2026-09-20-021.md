When your EC2 Windows instance (`windows-dev-test-pc`) is **stopped**:

| Component                        | While Running                     | While Stopped                 | Notes                                      |

### Python Cost Calculator Script

A standalone Python script has been created at
[aws/calculate_ec2_cost.py](file:///C:/usr/src/df/manuals/aws/calculate_ec2_cost.py).
It uses only the Python standard library (no `pip install` required) and
automatically inspects your instance, attached EBS volumes, IOPS/throughput
settings, and any Elastic IPs via the AWS CLI.

#### How to Run

```powershell
python aws/calculate_ec2_cost.py
```

You can also pass a specific instance name or ID:

```powershell
python aws/calculate_ec2_cost.py windows-dev-test-pc
```

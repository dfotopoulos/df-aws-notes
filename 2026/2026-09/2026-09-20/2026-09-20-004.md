## Summary

To enable your IAM user (such as `df`) to manage your EC2 instance, you need to
attach an IAM policy to that user in the AWS Console.

I have documented the complete configuration in
[ `docs/iam-ec2-management.md`](file:///C:/usr/src/df/cloud/aws/df-aws/docs/iam-ec2-management.md).
Here is the fastest way to do it:

---

### Step 1: Attach EC2 Policy in AWS Console

_(Perform these steps while logged in with your Root or Admin account)_

1. In the top search bar of the AWS Console, search for **IAM** &rarr; select
   **IAM**.
2. Click **Users** in the left sidebar.
3. Click on your IAM user (e.g. `df`).
4. Select the **Permissions** tab.
5. Click **Add permissions** &rarr; select **Add permissions**.
6. Select **Attach policies directly**.
7. In the search box, type:
    ```text
    AmazonEC2FullAccess
    ```
8. Select the checkbox next to `AmazonEC2FullAccess`.
9. Click **Next** at the bottom right, then click **Add permissions**.

Your IAM user now has full permissions to start, stop, reboot, modify security
groups, and view all EC2 instances and VPC resources.

---

### Step 2 (Optional): Enable AWS CLI Management for this User

If you want to manage instances directly from your PowerShell terminal:

1. On the same IAM User page for `df`, click the **Security credentials** tab.
2. Scroll to **Access keys** &rarr; click **Create access key**.
3. Choose **Command Line Interface (CLI)** &rarr; check confirmation &rarr;
   **Next** &rarr; **Create access key**.
4. Copy the **Access key ID** and **Secret access key**.
5. In your local PowerShell terminal, run:
    ```powershell
    aws configure
    ```
    - **Access Key ID**: _(paste key)_
    - **Secret Access Key**: _(paste secret)_
    - **Default region name**: `eu-central-1`
    - **Default output format**: `json`

You can then control your Windows instance from PowerShell:

```powershell
# Check instance status
aws ec2 describe-instances --instance-ids i-0c69f686dce985f3f --query "Reservations[*].Instances[*].[InstanceId,State.Name,PublicIpAddress]" --output table

# Stop instance (when not in use to avoid charges)
aws ec2 stop-instances --instance-ids i-0c69f686dce985f3f

# Start instance again
aws ec2 start-instances --instance-ids i-0c69f686dce985f3f
```

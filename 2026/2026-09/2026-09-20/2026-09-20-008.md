```powershell
aws ec2 start-instances --instance-ids i-0c69f686dce985f3f
```


> - The
>   [`.\scripts\manage-vm.ps1 connect`](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1)
>   script automatically detects the newly assigned DNS each time.

### 2. How to STOP the VM (Save Costs)

#### Why Stop It?

Your instance is a `t3.large` Windows machine. Running 24/7 costs roughly
**~$95 - $100 / month**. When stopped, **compute billing drops to $0.00/hr**
(you only pay pennies for the idle EBS disk storage).

#### CLI Command:

```powershell
aws ec2 stop-instances --instance-ids i-0c69f686dce985f3f
```

#### Wait for it to finish stopping:

```powershell
aws ec2 wait instance-stopped --instance-ids i-0c69f686dce985f3f
```

### 3. How to REMOTE DESKTOP on It

#### Method A: Automated (Copies password to clipboard & launches RDP)

```powershell
.\scripts\manage-vm.ps1 connect
```

- Automatically resolves the current DNS name.
- Automatically decrypts the Administrator password with your PEM key.
- Copies the password directly into your Windows clipboard.
- Opens `mstsc`—you simply press `Ctrl + V` in the password prompt.

#### Method B: Manual CLI

```powershell
# 1. Decrypt password
aws ec2 get-password-data --instance-id i-0c69f686dce985f3f --priv-launch-key "C:\opt\msys\home\df\.ssh\rsa-sweden-aws.pem"

# 2. Get current FQDN
aws ec2 describe-instances --instance-ids i-0c69f686dce985f3f --query "Reservations[0].Instances[0].PublicDnsName" --output text

# 3. Launch RDP with FQDN (avoids Windows 11 Error 0x1808)
mstsc /v:ec2-3-79-101-95.eu-central-1.compute.amazonaws.com
# Username: .\Administrator
```

### 4. How to GET ALL DETAILS on CLI

#### A. Clean Overview Table (ID, State, Type, Public IP, DNS):

```powershell
aws ec2 describe-instances --instance-ids i-0c69f686dce985f3f --query "Reservations[*].Instances[*].[InstanceId,State.Name,InstanceType,PublicIpAddress,PublicDnsName]" --output table
```

#### B. Status Checks (System & Instance 2/2 Health):

```powershell
aws ec2 describe-instance-status --instance-ids i-0c69f686dce985f3f --output table
```

#### C. Network, VPC, Subnet & Security Groups:

```powershell
aws ec2 describe-instances --instance-ids i-0c69f686dce985f3f --query "Reservations[0].Instances[0].{VpcId:VpcId,SubnetId:SubnetId,PrivateIp:PrivateIpAddress,PublicIp:PublicIpAddress,SecurityGroups:SecurityGroups[*].GroupId}" --output json
```

#### D. Attached EBS Storage Volumes:

```powershell
aws ec2 describe-instances --instance-ids i-0c69f686dce985f3f --query "Reservations[0].Instances[0].BlockDeviceMappings" --output json
```

#### E. Complete Raw Metadata (All attributes tracked by AWS):

```powershell
aws ec2 describe-instances --instance-ids i-0c69f686dce985f3f --output json
```

### 1. How to List All VMs

To query and list all virtual machines in your AWS region, use
`aws ec2 describe-instances` with a JMESPath projection to format the output
into a clean, human-readable table. This command extracts the Instance ID, the
custom Name tag (`windows-dev-test-pc`), the current lifecycle state (`running`,
`stopped`, etc.), the instance type (`t3.large`), and both public and private IP
addresses:

```powershell
aws ec2 describe-instances --query "Reservations[*].Instances[*].[InstanceId,Tags[?Key=='Name'].Value|[0],State.Name,InstanceType,PublicIpAddress,PrivateIpAddress]" --output table
```

_(You can also use our automation script: `.\scripts\manage-vm.ps1 list`). If
you wish to filter the list to display only running machines, append
`--filters "Name=instance-state-name,Values=running"`, or to filter exclusively
for Windows machines, append `--filters "Name=platform,Values=windows"`._

### 2. How to Delete a VM (Termination vs. Stopping & Pricing)

**You are entirely correct.** In AWS, deleting a virtual machine is officially
called **Terminating** the instance (`terminate-instances`), which is
fundamentally different from **Stopping** it:

- **When you STOP a VM**: Only the virtual CPU and RAM compute charges stop
  ($0.00/hr). However, the virtual hard disk (EBS volume) is kept intact in AWS
  storage so your files are preserved, which incurs a small ongoing disk storage
  fee (~$ 0.10 per GB/month, or ~$3.00/month for a 30 GB disk).
- **When you TERMINATE a VM**: The virtual machine is **permanently discarded
  and deleted**, and by default its attached root EBS storage volume is wiped
  (`DeleteOnTermination: true`). **All billing for both compute and disk storage
  ceases completely ($0.00/month)**. This action is irreversible—the operating
  system and all files stored on the instance are permanently destroyed.

To terminate an instance via CLI, run:

```powershell
# Terminate and permanently discard the VM
aws ec2 terminate-instances --instance-ids i-0c69f686dce985f3f

# Wait until AWS confirms the instance is fully terminated
aws ec2 wait instance-terminated --instance-ids i-0c69f686dce985f3f
```

### 3. How to Create an Identical VM from Scratch

To deploy a new Windows Server 2025 instance that exactly mirrors your current
virtual machine—using the same Amazon Machine Image (AMI), network subnet,
security firewall, SSH key pair, and 30 GB gp3 SSD storage—use the
`aws ec2 run-instances` command with the exact configuration parameters from
your environment:

```powershell
aws ec2 run-instances `
    --image-id ami-00c776e9c84f3cb49 `
    --instance-type t3.large `
    --key-name rsa-sweden-aws `
    --security-group-ids sg-043f8722ce2abe795 `
    --subnet-id subnet-056112256a984f0ab `
    --associate-public-ip-address `
    --block-device-mappings '[{"DeviceName":"/dev/sda1","Ebs":{"VolumeSize":30,"VolumeType":"gp3","DeleteOnTermination":true}}]' `
    --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=windows-dev-test-pc-clone}]'
```

**What each parameter does:**

- `--image-id ami-00c776e9c84f3cb49`: Specifies the official AWS Microsoft
  Windows Server 2025 English Full Base image in `eu-central-1`.
- `--instance-type t3.large`: Allocates 2 vCPUs and 8 GiB of memory.
- `--key-name rsa-sweden-aws`: Pairs the instance with your existing key so you
  can decrypt the password using your local
  [`C:\opt\msys\home\df\.ssh\rsa-sweden-aws.pem`](file:///C:/opt/msys/home/df/.ssh/rsa-sweden-aws.pem)
  key.
- `--security-group-ids sg-043f8722ce2abe795`: Attaches your existing security
  group with inbound RDP (port 3389) open.
- `--subnet-id subnet-056112256a984f0ab`: Places the instance in your public
  subnet routed to the Internet Gateway.
- `--associate-public-ip-address`: Automatically assigns a public IPv4 address
  so it can be reached over the internet.
- `--block-device-mappings`: Provisions a 30 GB gp3 root drive marked with
  `DeleteOnTermination: true` so no leftover disk costs remain when you
  terminate it later.

_Once launched, wait 5–8 minutes for Windows Server 2025 to initialize, then
retrieve the Administrator password for the new instance ID using:_

```powershell
aws ec2 get-password-data --instance-id <NEW_INSTANCE_ID> --priv-launch-key "C:\opt\msys\home\df\.ssh\rsa-sweden-aws.pem"
```

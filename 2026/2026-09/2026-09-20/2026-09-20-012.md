### Method 1: Cloud-Native Factory Reset (Root Volume Replacement)

_This is the cleanest and most powerful approach: it replaces the entire virtual
hard drive with a brand-new, clean disk directly from the base Windows Server
2025 AMI._

#### What It Does:

- **100% Wipes** all added applications (PowerToys, etc.), temporary files,
  registry changes, and secondary user accounts (`df`).
- **Preserves** your Instance ID (`i-0c69f686dce985f3f`), Public IP, and
  Security Groups.
- Takes approximately **1–2 minutes**.

#### How to Run via Automation Script:

Run in your local PowerShell terminal:

```powershell
.\scripts\manage-vm.ps1 reset
```

_(The script asks for confirmation, triggers the AWS
`create-replace-root-volume-task` API, deletes the old volume so no extra disk
costs occur, and monitors it until completion)._

#### Or via Direct AWS CLI:

```powershell
aws ec2 create-replace-root-volume-task `
    --instance-id i-0c69f686dce985f3f `
    --delete-replaced-root-volume
```

### Method 2: In-Guest Application Purge Script

_If you want to remove the installed software inside Windows without wiping the
entire operating system disk or rebooting:_

I created the script
[ `scripts/purge-installed-apps.ps1`](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/purge-installed-apps.ps1).

#### What It Does:

1. **Uninstalls packages via `winget`**: Silently uninstalls
   `Microsoft.PowerToys`, `Git.Git`, `Google.Chrome`, and
   `Microsoft.VisualStudioCode`.
2. **Cleans leftover directories**: Removes `C:\Program Files\PowerToys` and
   global start menu shortcuts in `C:\ProgramData`.
3. **Flushes temporary files**: Empties `C:\Windows\Temp` and user `%TEMP%`
   caches.
4. **Optional user account removal**: Pass `-KeepUser $false` to also delete the
   local `df` user account.

#### How to Run:

Inside your Remote Desktop session, open **PowerShell as Administrator** and
run:

```powershell
# Run the purge script:
& "C:\path\to\purge-installed-apps.ps1"

# Or if you also want to remove the 'df' user account:
& "C:\path\to\purge-installed-apps.ps1" -KeepUser $false
```

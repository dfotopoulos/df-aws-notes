## Summary

### 1. How to Monitor the Booting Status

AWS provides several methods to monitor the booting progress of your Windows
instance:

#### Method A: Visual Screen Capture (Live Screenshot of the Windows Display)

You can take an actual screenshot of the Windows virtual monitor directly from
AWS to see if it is on the boot screen or lock screen:

```powershell
.\scripts\manage-vm.ps1 screenshot
```

_(This downloads the real-time frame from the virtual GPU, saves it to
`scripts/screenshot.jpg`, and opens the image automatically)._

---

#### Method B: Check Status Checks (2/2 Passed)

```powershell
aws ec2 describe-instance-status --instance-ids i-0c69f686dce985f3f --output table
```

- **`InstanceStatus: initializing`**: Windows is still booting, loading drivers,
  and running `EC2Launch`.
- **`InstanceStatus: ok`**: Windows has finished booting, passed all operating
  system health checks, and is ready for connections.

---

#### Method C: Wait Automatically for Boot Completion

To pause your terminal until Windows has completely booted and passed all 2/2
checks:

```powershell
aws ec2 wait instance-status-ok --instance-ids i-0c69f686dce985f3f
```

---

#### Method D: Test When Port 3389 (RDP) Becomes Reachable

```powershell
Test-NetConnection -ComputerName 3.79.101.95 -Port 3389
```

When `TcpTestSucceeded : True`, the Windows Remote Desktop Service is active and
accepting connections.

### 2. With Which Command to Connect Again

#### Option 1: As `Administrator` (Copies decrypted password to clipboard)

```powershell
.\scripts\manage-vm.ps1 connect
```

_Simply press `Ctrl + V` in the password prompt._

#### Option 2: As `df` (If you created the user `df`)

```powershell
.\scripts\manage-vm.ps1 connect -Username df
```

_Enter your custom password when prompted._

#### Option 3: Manual Command Line (`mstsc`)

```cmd
mstsc /v:ec2-3-79-101-95.eu-central-1.compute.amazonaws.com
```

```powershell

# 2. Lock down Windows file permissions (ACL) on the private key
icacls "C:\opt\msys\home\df\.ssh\rsa-sweden-aws.pem" /inheritance:r /grant:r "$( $env:USERNAME ):(R,W)"

# 3. Validate structural integrity of the generated RSA PEM key
```

- **Why**: AWS EC2 Windows password decryption **strictly requires an
  OpenSSH/PEM formatted key** (`-----BEGIN RSA PRIVATE KEY-----`) and rejects
  PuTTY `.ppk` files.
- **`icacls` command**: Removes inherited group permissions (`BUILTIN\Users`)
  and grants exclusive read/write access to your user, preventing SSH/AWS tools
  from rejecting the key as unprotected.

When a root volume replacement (factory reset) completes, Windows boots up as a
completely fresh installation and EC2 generates a **brand-new random
Administrator password** encrypted with your key pair.

I queried AWS for your instance's latest password data, and it was generated at
**13:59:33 UTC**:

### How to Retrieve It Yourself

#### Method 1: Using the AWS CLI

Run this command in your PowerShell terminal anytime to fetch and decrypt the
current password:

```powershell
aws ec2 get-password-data --instance-id i-0c69f686dce985f3f --priv-launch-key "C:\opt\msys\home\df\.ssh\rsa-sweden-aws.pem"
```

**Output:**

```json
{
    "InstanceId": "i-0c69f686dce985f3f",
    "Timestamp": "2026-09-20T13:59:33+00:00",
    "PasswordData": "=j-b;ReGLmvUf!U0rvF$SA@z-A8i(5;$"
}
```

---

#### Method 2: Automatic 1-Click Connect

Our automation script always queries AWS for the latest password dynamically,
copies it to your clipboard, and launches Remote Desktop:

```powershell
.\scripts\manage-vm.ps1 connect
```

_(Simply press `Ctrl + V` in the Windows password box)._

---

#### Method 3: In the AWS Console

1. Open the [EC2 Console](https://console.aws.amazon.com/ec2/home#Instances:).
2. Select instance `i-0c69f686dce985f3f` &rarr; click **Connect** (top right).
3. Under the **RDP client** tab, click **Get password**.
4. Upload:
    ```text
    C:\opt\msys\home\df\.ssh\rsa-sweden-aws.pem
    ```
5. Click **Decrypt password**.

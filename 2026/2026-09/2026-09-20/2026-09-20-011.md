## Summary

To log into Windows Remote Desktop (`mstsc`) with a different account such as
**`df`**, there are two quick steps:

---

### Step 1: Create the User Inside the Remote Windows VM

Because AWS Windows AMIs only contain the default `Administrator` user out of
the box, the account `df` must first be created inside the Windows Operating
System:

1. Connect to the VM as `Administrator` (e.g.
   `.\scripts\manage-vm.ps1 connect`).
2. Inside the remote desktop, open **PowerShell as Administrator** and run:
    ```powershell
    # 1. Create the user 'df' with your preferred password
    net user df "YourSecurePassword123!" /add

    # 2. Grant Administrator rights (optional, but recommended)
    net localgroup Administrators df /add

    # 3. Grant Remote Desktop access permission (mandatory for RDP)
    net localgroup "Remote Desktop Users" df /add
    ```
3. Disconnect from Remote Desktop.

---

### Step 2: Connect via `mstsc` as `df`

#### Option A: Using the Automation Script

I updated
[`scripts/manage-vm.ps1`](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1)
to accept a `-Username` parameter:

```powershell
.\scripts\manage-vm.ps1 connect -Username df
```

This automatically configures the session for user `.\df` and opens Remote
Desktop. Type your password when prompted.

#### Option B: Using the Standard `mstsc` GUI

1. Run in PowerShell or `Win + R`:
    ```cmd
    mstsc /v:ec2-3-79-101-95.eu-central-1.compute.amazonaws.com
    ```
2. When the Windows Security credential prompt appears:
    - Click **More choices** &rarr; **Use a different account**.
    - **User name**: `.\df` _(The `.\` prefix is critical: it tells Windows to
      authenticate against the remote VM rather than your local machine)_.
    - **Password**: `YourSecurePassword123!`
3. Click **OK** to connect.

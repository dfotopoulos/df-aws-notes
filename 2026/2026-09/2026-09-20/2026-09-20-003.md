# 2026-09-20-003

## Summary

### Why Error `0x1808` Occurred

On Windows 11, if you are logged in to your local PC with a Microsoft / Web
account, `mstsc.exe` attempts to send web authentication tokens when given a
bare IP address (`3.79.101.95`). Windows rejects this with:

> _Error code: 0x1808 – "Using an IP address is not supported. When using a web
> account to sign in to the remote computer, you must provide a NetBIOS domain
> name or fully qualified domain name (FQDN)..."_

---

### How to Connect (Choose Either Option)

#### Option 1 (Easiest): Double-click the preconfigured `.rdp` file

I have generated a ready-to-use RDP profile file for your instance in your
workspace:
[`windows-dev-test-pc.rdp`](file:///C:/usr/src/df/cloud/aws/df-aws/windows-dev-test-pc.rdp)

1. Double-click
   [`windows-dev-test-pc.rdp`](file:///C:/usr/src/df/cloud/aws/df-aws/windows-dev-test-pc.rdp).
2. Enter:
    - **User name**: `.\Administrator` (the `.\` tells Windows to authenticate
      against the remote machine instead of your local Microsoft account)
    - **Password**: _(your decrypted password)_
3. Click **Connect** (and accept the certificate warning).

#### Option 2: Connect via PowerShell / Run command using FQDN

Run this command in PowerShell or the `Win + R` Run dialog:

```cmd
mstsc /v:ec2-3-79-101-95.eu-central-1.compute.amazonaws.com
```

When prompted for credentials:

- Click **More choices** &rarr; **Use a different account**.
- **User name**: `.\Administrator`
- **Password**: _(paste your decrypted password)_

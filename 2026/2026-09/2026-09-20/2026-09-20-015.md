### Individual Commands by Identification Category

#### A. Root User & Account Identification

1. **AWS Account ID & Root ARN**:

    ```powershell
    aws sts get-caller-identity --query "Account" --output text
    ```
    - **Root ARN**: `arn:aws:iam::<ACCOUNT_ID>:root`
      (`arn:aws:iam::275517639819:root`).

2. **Account Aliases & Custom Login URL**:

    ```powershell
    aws iam list-account-aliases
    ```
    - **Login URL**: `https://275517639819.signin.aws.amazon.com/console` (or
      with custom alias if created).

3. **Root Security Posture (MFA & Access Keys)**:

    ```powershell
    aws iam get-account-summary --query "SummaryMap.{AccountMFAEnabled:AccountMFAEnabled,AccountAccessKeysPresent:AccountAccessKeysPresent}" --output table
    ```
    - Confirms that Root MFA is enabled (`1`) and Root Access Keys are absent
      (`0`).

---

#### B. IAM User (`df`) Identification

1. **Profile, Unique ID & Timestamps**:

    ```powershell
    aws iam get-user --user-name df
    ```
    - **`UserId` (`AIDAUAJRBRSF3FKJEEUIW`)**: The immutable AWS unique internal
      ID.
    - **`Arn` (`arn:aws:iam::275517639819:user/df`)**: The resource name used in
      IAM policies.

2. **Attached IAM Policies**:

    ```powershell
    aws iam list-attached-user-policies --user-name df
    ```
    - Lists policies granting permissions (e.g. `AdministratorAccess`).

3. **Group Memberships**:

    ```powershell
    aws iam list-groups-for-user --user-name df
    ```
    - Shows groups the user belongs to (e.g. group `df`, ID:
      `AGPAUAJRBRSF25EEYGEMY`).

4. **Programmatic Access Keys**:

    ```powershell
    aws iam list-access-keys --user-name df
    ```
    - Reports the active `AccessKeyId` (`AKIAUAJRBRSF3HMLY5YG`) used by the AWS
      CLI.

5. **Assigned MFA Devices**:

    ```powershell
    aws iam list-mfa-devices --user-name df
    ```
    - Reports multi-factor devices (e.g. `arn:aws:iam::275517639819:mfa/Zeus`).

6. **Assigned Metadata Tags**:

    ```powershell
    aws iam list-user-tags --user-name df
    ```

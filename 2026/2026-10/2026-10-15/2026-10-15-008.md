## Summary

The `modify` command has been implemented in
[scripts/manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1).

It leverages the **AWS Systems Manager (SSM)** agent running on the EC2 instance
to execute guest-level commands directly from your PowerShell terminal without
requiring manual RDP login.

---

### What It Does

When you run `modify` with `-NewUser` (or `-User` / `-AddUser`):

1. **Creates or updates the Windows local account** inside the running instance.
2. **Grants permissions**: Adds the user to both `Administrators` and
   `Remote Desktop Users`.
3. **Sets `PasswordNeverExpires: True`**.
4. **Copies password**: Securely copies the password to your local Windows
   clipboard.
5. **Updates RDP shortcut**: Configures
   [windows-dev-test-pc.rdp](file:///C:/usr/src/df/cloud/aws/df-aws/windows-dev-test-pc.rdp)
   to connect as `.\<user>`.

---

### CLI Usage Examples

#### 1. Create or update user `df` on the current VM

```powershell
.\scripts\manage-vm.ps1 modify -NewUser df
```

_(Prompts for a password, or generates a secure random one if left blank)_

#### 2. Create user with a specific password

```powershell
.\scripts\manage-vm.ps1 modify -User df -Password "YourSecurePassword#2026!"
```

#### 3. Target a specific VM by Name

```powershell
.\scripts\manage-vm.ps1 modify -Name nanomegas-format-code -User df
```

#### 4. Connect as the new user

```powershell
.\scripts\manage-vm.ps1 connect -Username df
```

_(Or launch the updated
[windows-dev-test-pc.rdp](file:///C:/usr/src/df/cloud/aws/df-aws/windows-dev-test-pc.rdp))_

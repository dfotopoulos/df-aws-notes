# 2026-10-15-010

## Summary

The `teardown` command (along with its aliases `purge` and `destroy`)
in [scripts/manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1) now enforces a **mandatory VM
name**.

---

### What Was Updated

1. **Mandatory Name Enforcement**:
    - Running `teardown` without a name prompts interactively:
      ```text
      Enter the mandatory VM name to teardown:
      ```
    - If left blank, cancelled, or passed without a name under `-Force`, it halts safely:
      ```text
      [-] The teardown command did not succeed because the VM name is mandatory. Please specify -Name <NAME>.
      ```
2. **Explicit Confirmation**:
    - The safety confirmation prompt displays the specific VM name being purged:
      ```text
      Type 'YES' to permanently purge and delete instance 'nanomegas-format-code'
      ```
3. **Positional & Named Parameter Support**:
    - Supports both named flag and positional syntax:
        - `.\scripts\manage-vm.ps1 teardown -Name <VM_NAME>`
        - `.\scripts\manage-vm.ps1 teardown <VM_NAME>`
4. **State Awareness**:
    - If the instance is already in `terminated` state, it returns cleanly without attempting redundant API termination.

---

### Usage Examples

```powershell
# Flag syntax
.\scripts\manage-vm.ps1 teardown -Name my-test-vm

# Positional syntax
.\scripts\manage-vm.ps1 teardown my-test-vm

# Using purge alias
.\scripts\manage-vm.ps1 purge -Name my-test-vm
```

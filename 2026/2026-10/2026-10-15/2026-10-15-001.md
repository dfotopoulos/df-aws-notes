### Windows 11 on AWS EC2 Note

AWS EC2 does not offer consumer Windows 11 (Client Pro/Enterprise) on standard
multi-tenant instances due to Microsoft BYOL licensing restrictions requiring
Dedicated Hosts.

However, **Microsoft Windows Server 2025 Base** is built directly on the
**Windows 11 (24H2, Build 26100)** codebase and provides the exact same Windows
11 Desktop Experience (GUI, Start Menu, Settings, WinGet, Windows Terminal, and
compatibility with desktop apps like Visual Studio and Qt Creator), with
licensing included per-second. The script dynamically resolves the latest
official image from AWS SSM:
`/aws/service/ami-windows-latest/Windows_Server-2025-English-Full-Base`

### 1. Tearing Down / Purging the VM

The **`teardown`** (or **`purge`**) action completely terminates the instance
and deletes its attached root EBS volume, reducing all ongoing compute and disk
storage costs to **$0.00**.

#### Usage:

```powershell
# Interactive confirmation (prompts you to type 'YES')
.\scripts\manage-vm.ps1 teardown

# Or bypass confirmation prompt
.\scripts\manage-vm.ps1 teardown -Force

# Or specify a different instance ID
.\scripts\manage-vm.ps1 teardown -InstanceId i-0c69f686dce985f3f -Force
```

#### What It Does:

1. Shows a warning that all disk data will be permanently wiped.
2. Prompts for confirmation (`YES`) unless `-Force` is passed.
3. Issues `aws ec2 terminate-instances` and waits until AWS reports
   `terminated`.
4. Confirms that compute and storage charges have completely ceased.

### 2. Creating a Fresh Windows 11 / Server 2025 VM

The **`create`** action provisions a brand-new instance from the latest clean
AWS image with your networking and security group settings.

#### Usage:

```powershell
# Create with default settings (t3.large, 120 GB gp3 SSD, rsa-sweden-aws key)
.\scripts\manage-vm.ps1 create

# Or create with custom specs (e.g. t3.xlarge, 150 GB disk, no prompt)
.\scripts\manage-vm.ps1 create -InstanceType t3.xlarge -VolumeSize 150 -Force

# Or pass a bootstrap user-data script
.\scripts\manage-vm.ps1 create -UserDataPath "C:\path\to\bootstrap.ps1"
```

#### What It Does Automatically:

1. **Queries SSM**: Automatically resolves the latest official
   `Windows_Server-2025-English-Full-Base` AMI ID.
2. **Provisions Storage**: Attaches a `120 GB gp3` SSD with
   `DeleteOnTermination: true`.
3. **Applies VPC & Security**: Binds your existing public subnet
   (`subnet-056112256a984f0ab`), RDP security group (`sg-043f8722ce2abe795`),
   and key pair (`rsa-sweden-aws`).
4. **Waits for Boot**: Waits until EC2 reaches `running` state and fetches the
   assigned Public IP and DNS.
5. **Syncs Configuration**: Automatically updates the default `$InstanceId` in
   [manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1)
   and updates the RDP file
   [windows-dev-test-pc.rdp](file:///C:/usr/src/df/cloud/aws/df-aws/windows-dev-test-pc.rdp)
   so subsequent commands (`status`, `connect`, `start`, `stop`) work
   immediately with the new VM.

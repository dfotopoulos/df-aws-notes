# 2026-10-15-006

## Summary

The feature has been added to
[scripts/manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1).

You can now list all instances or filter specifically for running instances:

---

### Usage

#### 1. List ONLY Running VMs

You can use either the `running` action or the `-Running` switch:

```powershell
.\scripts\manage-vm.ps1 running
```

_or_

```powershell
.\scripts\manage-vm.ps1 list -Running
```

**Output:**

```text
Listing RUNNING EC2 instances...

Name                InstanceId          State   Type     PublicIP    PrivateIP     LaunchTime
----                ----------          -----   ----     --------    ---------     ----------
windows-dev-test-pc i-0c69f686dce985f3f running t3.large 54.93.47.77 172.31.20.168 2026-10-15T12:32:51+00:00

Total: 1 instance(s)
```

_(If no instances are running, it clearly reports
`[-] No running EC2 instances found.`)_

---

#### 2. List ALL VMs (Running, Stopped, Pending)

```powershell
.\scripts\manage-vm.ps1 list
```

**Output:**

Total: 1 instance(s)

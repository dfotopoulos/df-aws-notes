# 2026-10-15-013

## Summary

Here are the exact commands to create both VMs with the administrator user **`df`**:

---

### VM 1: `windows-dev-test-pc`

```powershell
.\scripts\manage-vm.ps1 create -Name windows-dev-test-pc -NewUser df
```

*(You will be prompted to enter the password for `df` and confirm launch with `YES`)*

---

### VM 2: `nanomegas-format-code`

```powershell
.\scripts\manage-vm.ps1 create -Name nanomegas-format-code -NewUser df
```

*(You will be prompted to enter the password for `df` and confirm launch with `YES`)*

---

### Optional: Fully Automated One-Liners (Specify Password Directly)

If you prefer not to be prompted and want to specify the password directly:

```powershell
# Create windows-dev-test-pc
.\scripts\manage-vm.ps1 create -Name windows-dev-test-pc -NewUser df -NewUserPassword "YourPassword#2026!" -Force

# Create nanomegas-format-code
.\scripts\manage-vm.ps1 create -Name nanomegas-format-code -NewUser df -NewUserPassword "YourPassword#2026!" -Force
```

---

### What Happens Automatically

During boot, each VM will:

1. Provision the local Windows account **`df`**.
2. Add `df` to both **`Administrators`** and **`Remote Desktop Users`**.
3. Configure password never to expire.
4. Update [windows-dev-test-pc.rdp](file:///C:/usr/src/df/cloud/aws/df-aws/windows-dev-test-pc.rdp) with
   `username:s:.\df` and the new public host address.

---

### How to Connect

Once created and booted, connect as user `df` with:

```powershell
# Connect to windows-dev-test-pc
.\scripts\manage-vm.ps1 connect -Name windows-dev-test-pc -Username df

# Connect to nanomegas-format-code
.\scripts\manage-vm.ps1 connect -Name nanomegas-format-code -Username df
```

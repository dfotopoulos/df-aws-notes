# 2026-10-15-009

## Summary

The `stop` command in
[scripts/manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1)
now enforces a **mandatory VM name**.

---

### What Was Updated

1. **Mandatory Name Enforcement**:
    - If you run `stop` without a name, the script prompts:
        ```text
        Enter the mandatory VM name to stop:
        ```
    - If left blank or cancelled, it smoothly halts without touching any VM:
        ```text
        [-] The stop command did not succeed because the VM name is mandatory. Please specify -Name <NAME>.
        ```
2. **Positional Parameter Support**:
    - The VM name is configured as `Position = 1`, allowing both flag syntax and
      positional syntax:
        - Flag syntax: `.\scripts\manage-vm.ps1 stop -Name <VM_NAME>`
        - Positional syntax: `.\scripts\manage-vm.ps1 stop <VM_NAME>`
3. **State Awareness**:
    - If the target instance is already `stopped` or currently `stopping`, it
      gracefully informs you rather than throwing an AWS error:
        ```text
        [-] Instance 'nanomegas-format-code' (i-078f78f26356eb712) is already stopped.
        ```

---

### Usage Examples

```powershell
# Flag syntax
.\scripts\manage-vm.ps1 stop -Name windows-dev-test-pc

# Positional syntax
.\scripts\manage-vm.ps1 stop nanomegas-format-code
```

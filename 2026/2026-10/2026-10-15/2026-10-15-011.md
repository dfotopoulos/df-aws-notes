### Why They Still Appear as `Terminated`

1. **`Terminated` is the final, irreversible state in AWS EC2:**
    - The virtual machines have ceased to exist.
    - All network interfaces and public IP addresses were released back to AWS.
    - All attached EBS root volumes were permanently deleted (`DeleteOnTermination = true`).
2. **AWS Retention Window (Audit & History):**
    - AWS deliberately keeps terminated instances visible in the web console and API for **approximately 1 to 2 hours**
      after termination so that administrators and audit logs have a reference that the deletion completed.
    - After this period, AWS automatically and permanently purges them from the console list entirely.
3. **Billing is strictly $0.00:**
    - Billing stopped the exact second they transitioned to `Terminated`.
    - We just verified your AWS account directly:
      ```text
      aws ec2 describe-volumes
      {
          "Volumes": []
      }
      ```
      There are **0 EBS storage volumes** and **0 running instances** remaining in the region.

### How to Hide Terminated Instances Right Now

#### 1. In the AWS Console:

In the search box above the table (*"Filter Instance by attribute or tag"*):

- Click the filter box and select **Instance state** ➔ **running** (or **Instance state** ➔ **!=** ➔ **terminated**).
- Or click the **Saved filter sets** dropdown on the top-left and select **Running instances**.

#### 2. From your CLI:

You can use the `running` command
in [scripts/manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1):

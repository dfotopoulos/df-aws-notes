## Summary

The changes have been implemented and tested in
[scripts/manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1).

---

### What Was Updated

1. **Mandatory `-Name` for Creation**:
    - Removed the static default name.
    - When running `create`, if `-Name` is omitted:
        - Interactive run: Prompts `Enter the mandatory VM name`.
        - If left empty or run non-interactively (`-Force`): Returns smoothly
          with:
            ```text
            [-] The creation of the VM did not succeed because the VM name is mandatory. Please specify -Name <NAME>.
            ```

2. **Duplicate VM Name Detection & Smooth Return**:
    - Queries AWS EC2 for existing active instances (`pending`, `running`,
      `stopping`, `stopped`) matching that Name tag.
    - If an active VM with that name already exists, it aborts the launch
      immediately and returns smoothly (exit code 0) with:
        ```text
        [-] The creation of the VM with name '{NAME}' did not succeed because it already exists (Instance ID: {ID}, State: {STATE}).
        ```

3. **Universal `-Name` Resolution Across All Commands**:
    - You can now also pass `-Name <NAME>` to any other command (`status`,
      `start`, `stop`, `connect`, `teardown`), and the script will automatically
      look up the active instance ID by its Name tag.

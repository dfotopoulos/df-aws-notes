## Summary

**Yes, absolutely.** You can specify a custom username both for **newly created
VMs** and on your **existing VM**.

---

### Option 1: On Any New VM (`create` with `-NewUser`)

[scripts/manage-vm.ps1](file:///C:/usr/src/df/cloud/aws/df-aws/scripts/manage-vm.ps1)
has been updated with `-NewUser` and `-NewUserPassword` parameters. When you run
`create`, it automatically provisions the user account during initial boot via
AWS EC2 User Data and adds them to both `Administrators` and
`Remote Desktop Users`.

```powershell
.\scripts\manage-vm.ps1 create -Name my-new-vm -NewUser dimitri
```

- **Interactive prompt**: The script will prompt you to enter a password for the
  new user (or auto-generates a strong random password if run with `-Force`).
- **Automatic RDP setup**: Configures
  [windows-dev-test-pc.rdp](file:///C:/usr/src/df/cloud/aws/df-aws/windows-dev-test-pc.rdp)
  with `username:s:.\dimitri`.
- **Direct connect**: Once ready, you can connect directly with:
    ```powershell
    .\scripts\manage-vm.ps1 connect -Username dimitri
    ```

---

### Option 2: On the Currently Running VM (`nanomegas-format-code`)

Because EC2 User Data executes only on the initial instance launch, you can add
a new user to your currently active instance in 3 quick commands:

1. **Connect via RDP as Administrator**:

    ```powershell
    .\scripts\manage-vm.ps1 connect
    ```

    _(The Administrator password `)rN%THo9Gt@5OAVM$MO)X&taV?Y1j4bj` is already
    copied to your clipboard — just press <kbd>Ctrl</kbd>+<kbd>V</kbd> when
    prompted)_

2. **Open PowerShell inside the Windows VM** and run:

    ```powershell
    net user <NEW_USERNAME> "<NEW_PASSWORD>" /add /y
    net localgroup Administrators <NEW_USERNAME> /add
    net localgroup "Remote Desktop Users" <NEW_USERNAME> /add
    ```

3. **Connect as your new user anytime from your host**:
    ```powershell
    .\scripts\manage-vm.ps1 connect -Username <NEW_USERNAME>
    ```
